常见问题

如何获取 DeepSeek API Key？
在 DeepSeek 开放平台（platform.deepseek.com）注册账号并充值后，在「API Keys」页面创建一个密钥。调用费用由您的 DeepSeek 账户承担。

在哪里填写 API Key？
打开 λόγος，进入「设置」，在「DeepSeek API Key」一栏粘贴密钥即可，修改后自动保存。密钥只保存在您的设备上。

查询时提示「API Key 无效」或「余额不足」？
请检查密钥是否完整粘贴、是否已在 DeepSeek 平台删除，以及账户余额是否充足。

iPhone 和 Mac 之间的数据没有同步？
请确认两台设备登录了同一个 Apple 账户，并在系统设置的 iCloud 中允许 λόγος 使用 iCloud。同步可能需要几分钟，打开 App 时会自动获取最新数据。API Key 不会同步，需要在每台设备上分别填写。

需要订阅或付费吗？
λόγος 本身免费，没有订阅和广告。查询解析的费用由您在 DeepSeek 平台的账户直接支付。
