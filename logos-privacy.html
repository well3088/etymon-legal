λόγος 隐私政策

生效日期：2026/10/19
更新日期：2026/10/19

λόγος（以下简称“本应用”）由 Shaopeng Wu（以下简称“我们”）开发。本应用无需注册账号，我们不运营任何服务器，不收集、不接收、也无法访问您的任何个人信息。请您在使用本应用前仔细阅读本政策。您继续使用本应用，即表示您已阅读并理解本政策的全部内容。

一、我们不收集的信息

我们不收集您的姓名、手机号码、电子邮件、位置、通讯录、照片、设备标识符或广告标识符（IDFA），不使用任何统计分析或广告服务，不进行跨应用追踪，也不展示广告。

二、在您设备上处理的信息

  1. API 密钥：您在设置中填写的 DeepSeek API 密钥仅保存在您的设备本地，只在您发起查询时随请求直接发送给 DeepSeek，用于验证您本人的 DeepSeek 账户。我们不会获得您的密钥。
  2. 学习数据：您查询过的单词与句子、解析结果、分类、复习与拼写记录，保存在您的设备上；如您开启了 iCloud，这些数据会同步到您本人的 iCloud 私有空间，由您通过 Apple 账户控制，我们无法访问。
  3. 偏好设置：发音口音、语速、复习与拼写的筛选条件等设置保存在您的设备上，并可能通过您本人的 iCloud 在您的设备之间同步。
  4. 发音：单词和句子的朗读由系统在设备本地完成。

三、您直接使用的第三方服务

本应用不经过任何中间服务器。您使用以下服务时，相关信息由您的设备直接发送给服务提供商，并适用其各自的服务条款和隐私政策：

服务提供商用途涉及的信息
杭州深度求索人工智能基础技术研究有限公司（DeepSeek）使用您本人的账户和密钥，对您提交的查询内容进行 AI 解析您提交的英文单词或句子、您的 API 密钥、网络请求必然产生的 IP 地址等技术信息
Apple Inc.（iCloud）在您的设备之间同步学习数据和偏好设置学习数据、偏好设置

DeepSeek 的服务器位于中华人民共和国境内。如您在其他国家或地区使用查询解析功能，您提交的查询内容将由您的设备直接传输至中华人民共和国境内处理。您与 DeepSeek 之间的账户关系、费用与数据处理，由您与 DeepSeek 直接约定。请勿在查询中输入您的个人信息或他人的个人信息。如您不同意上述处理，可以不填写 API 密钥、不使用查询解析功能，已保存内容的查看、复习与拼写功能不受影响。

四、您的权利

  1. 查阅、更正与删除：您的学习数据完全由您控制。您可以在应用内修改记录，通过系统设置删除本应用在 iCloud 中的数据，或卸载本应用删除设备上的数据。
  2. 撤回：您可以随时在设置中删除 API 密钥，或停止使用查询解析功能。
  3. 由于我们不持有您的任何个人信息，我们无法为您查询、导出或删除数据；涉及 DeepSeek 或 Apple 处理的信息，请按其各自的方式行使权利。

五、未成年人保护

如您是未满十四周岁的未成年人，请在监护人的陪同下阅读本政策，并在取得监护人同意后使用本应用。

六、信息安全与免责

  1. 本应用与 DeepSeek 之间的通信使用加密传输（HTTPS）。请妥善保管您的 API 密钥，因密钥泄露或在您的 DeepSeek 账户中产生的费用，由您与 DeepSeek 按其条款处理。
  2. 本应用的查询解析结果由人工智能自动生成，可能存在错误或不准确之处，仅供学习参考，不构成任何专业建议。

七、政策更新与联系我们

我们可能会适时更新本政策。更新后的政策将在本页面发布并更新上方的日期。
