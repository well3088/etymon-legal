常见问题

如何获取 DeepSeek API Key？
在 DeepSeek 开放平台（platform.deepseek.com）注册账号并充值后，在「API Keys」页面创建一个密钥。还没有密钥时，也可以在 λόγος 的「设置」中点击「获取」直接前往。调用费用由您的 DeepSeek 账户承担。

在哪里填写 API Key？
打开 λόγος，进入「设置」，在「DeepSeek API Key」中粘贴完整的密钥，点击「保存」。λόγος 会先验证密钥是否有效，验证通过后才会保存到设备的钥匙串中，并显示账户余额。为了安全，保存后只显示密钥的开头和结尾几位。

如何更换 API Key？
在「设置」的「更换密钥」中粘贴新的密钥并点击「保存」。新密钥验证通过后会替换旧的密钥；验证失败时，旧的密钥保持不变。

保存时提示「API Key 无效」？
请检查是否完整复制了密钥（包括开头的 sk-），以及该密钥是否已在 DeepSeek 平台被删除。

如何查看余额和用量？
每次打开「设置」时，λόγος 会显示您 DeepSeek 账户的余额。点击余额会在浏览器中打开 DeepSeek 平台的用量页面，可以查看明细和充值。查询余额不会产生费用。

查询时提示「余额不足」？
请在 DeepSeek 平台为账户充值后重试。

iPhone 和 Mac 之间的数据没有同步？
请确认两台设备登录了同一个 Apple 账户，并在系统设置的 iCloud 中允许 λόγος 使用 iCloud。同步可能需要几分钟，打开 App 时会自动获取最新数据。为了安全，API Key 不会同步，需要在每台设备上分别填写。

如何备份我的学习数据？
在「设置」中点击「导出数据」，可以将全部单词、分类、复习与拼写记录保存为一个 JSON 文件，存放在「文件」App、iCloud 云盘或电脑上的任意位置。

需要订阅或付费吗？
λόγος 本身免费，没有订阅和广告。查询解析的费用由您在 DeepSeek 平台的账户直接支付。
